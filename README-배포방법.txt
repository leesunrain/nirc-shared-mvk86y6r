여자 마스터즈 입상 유력자 매칭 v1.0.0

[신규 앱 / 최초 배포]
- 이 ZIP은 신규 앱 소스이며 실제 배포는 수행하지 않았습니다.
- 기존 앱 업데이트가 아닙니다. 기존 Vercel 프로젝트를 덮어쓰지 마세요.
- ZIP 압축을 풀고 폴더의 index.html, app.js, seed.json, manifest.webmanifest, icon.svg, sw.js를 한 프로젝트 루트에 배포하세요.
- Vercel에서 신규 프로젝트를 최초 1회 생성하거나, 본인이 사용하는 배포기로 신규 앱으로 등록하세요.
- 생성된 Production URL을 스마트폰에서 열고 홈 화면에 추가할 수 있습니다.

[중요]
- 초기 선수 170명은 원본 엑셀의 C열(입상유력선수)에서 추출했습니다. 참가자 비교용 J열 이후는 DB에 넣지 않았습니다.
- 기존 원본 엑셀은 변경하지 않았습니다. 동명이인, 기록 단위, 날짜 없는 자료는 직접 검토하세요.
- 26년 동마 기록은 2026 서울마라톤 풀코스로 저장했습니다. 정확한 경기 날짜는 원본에서 확인되지 않아 비워 두었습니다.
- 초기 기록 중 숫자 표기는 HHMMSS/MMSS 방식으로 해석을 시도했으나 원본 표기 그대로 보존합니다. 이상한 기록은 수동 수정하세요.
- 선수 DB는 IndexedDB에 저장됩니다. 브라우저 저장 데이터 삭제 시 사라질 수 있으므로 JSON 백업을 정기적으로 다운로드하세요.
- 외부 CDN의 xlsx/tesseract 라이브러리는 최초 접속 때 네트워크가 필요합니다. 사진 OCR 품질은 사진마다 다르며 확인이 필수입니다.
- 현재 XLSX 참가자 읽기는 첫 번째 시트 기준입니다. DB 엑셀 일괄 등록은 이름 열 기반의 신규 선수 추가만 지원합니다. 기존 기록을 포함한 완전한 엑셀 병합은 아직 미구현입니다.
- 파일을 단순 더블클릭(file://)하면 fetch/서비스워커가 차단될 수 있으니 HTTPS에서 실행하세요.

[향후 업데이트]
- 반드시 최초 배포된 Vercel projectId와 Production URL을 확인한 뒤 같은 프로젝트에 업데이트하세요.
- localStorage/IndexedDB 데이터는 삭제하지 마세요.
- 실제 배포 후 URL, 데이터 보존, OCR, 엑셀 입력을 직접 검증하세요.
